# HIDRA - Android version

HIDRA is the PWA that implements HID keyboard in HTML, JS and CSS based on esp32 WebSocket server that uses BLE

## Android version

* Implement a similar HID keyboard over BLE as Android app
* In this setup Android phone acts as a keyboard that is recognized in tablet (or some other device) as BLE Keboard
* Focus on Pixel Android phones
* Implement the keyboard as it was implemented in PWA (the HTML, JS and CSS implementation was very good in appearance and response)
* First milestone is feasibility check and phased plan for implementation
